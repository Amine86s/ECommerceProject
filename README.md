Full-Stack E-Commerce Platform

A modern full-stack e-commerce web application developed using React, Node.js, Express, and MongoDB.

Features
User authentication and authorization
Product listing system
Shopping cart functionality
Order management
RESTful API architecture
Responsive frontend design
Technologies
React.js
Node.js
Express.js
MongoDB
JavaScript
REST API
Run
Backend:
npm install
npm start
Frontend:
npm install
npm run dev
